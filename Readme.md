# Estudo da Propriedade Display em CSS

---

## 📋 Descrição do Projeto

Este projeto foi desenvolvido com o objetivo de **estudar, praticar e consolidar o conhecimento sobre a propriedade `display` no CSS**. 

Através de exemplos práticos e visuais, o repositório explora o comportamento dos diferentes valores dessa propriedade fundamental para o layout web, ajudando a entender como os elementos são renderizados e posicionados na página.

### 🔍 Conceitos Abordados
* **`display: none`**: Oculta o elemento completamente da página, removendo-o do fluxo visual.
* **`display: block`**: Faz com que o elemento ocupe toda a largura disponível, quebrando a linha antes e depois dele.
* **`display: inline-block`**: Permite que os elementos fiquem lado a lado (como os inline), mas mantendo a capacidade de definir largura, altura e espaçamentos (como os block).
* **`display: flex`**: Introduz o poderoso modelo de layout *Flexbox*, facilitando o alinhamento, a distribuição de espaço e a direção dos itens de forma responsiva.
